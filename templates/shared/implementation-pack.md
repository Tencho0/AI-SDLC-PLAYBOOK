# Implementation Pack

> Produced while implementing a story or fix to capture the change and its reasoning. Save the filled copy to `src/<engagement>/delivery/`.

## 1. Ticket understanding
_The team's understanding of what the ticket asks for._

## 2. Affected files/modules
_Files, modules, and components the change touches._

## 3. Implementation plan
_The intended approach and sequence of changes._

## 4. Code changes
_A summary of the actual code changes made._

## 5. Tests added/updated
_Tests created or modified to cover the change._

## 6. Commands run
_Build, test, and verification commands executed._

## 7. Risks
_Risks introduced or remaining after the change._

## 8. Documentation updates
_Documentation created or updated for the change._

## 9. PR summary
_A concise pull request description for reviewers._
