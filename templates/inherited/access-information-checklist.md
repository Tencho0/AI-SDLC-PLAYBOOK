# Access & Information Checklist

> Produced early in a takeover to confirm what access and information has been obtained. Save the filled copy to `src/<engagement>/delivery/`.

## 1. Repository access
_Whether and how source repository access has been granted._

## 2. Documentation received
_What documentation the client has provided._

## 3. Database schema availability
_Whether the database schema is available for review._

## 4. Deployment information
_Details about how and where the system is deployed._

## 5. CI/CD access
_Access to build and deployment pipelines._

## 6. Issue tracker access
_Access to the issue or ticket tracking system._

## 7. Support ticket history
_Availability of historical support tickets._

## 8. Test suite availability
_Whether an existing test suite is available._

## 9. Monitoring/logging access
_Access to monitoring dashboards and logs._

## 10. Missing information
_Information still needed but not yet received._

## 11. Blockers
_Anything preventing assessment or work from starting._

## 12. Client follow-up questions
_Questions to ask the client to close the gaps._
