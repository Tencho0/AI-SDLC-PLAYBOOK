# Business Rule Recovery Report

> Produced when reconstructing how an inherited system behaves from code, docs, and history. Save the filled copy to `src/<engagement>/delivery/`.

## 1. Current workflows
_The workflows the system supports as observed today._

## 2. User roles
_The roles that interact with the system._

## 3. Permissions
_What each role is allowed to do._

## 4. Business rules found in code
_Rules inferred directly from the source code._

## 5. Business rules found in documentation
_Rules stated in existing documentation._

## 6. Business rules found in historical tickets
_Rules implied by past tickets and change history._

## 7. Contradictions
_Where the discovered rules conflict with one another._

## 8. Unclear behavior
_Behavior that cannot be confidently explained yet._

## 9. Client validation questions
_Questions for the client to confirm the recovered rules._

## 10. Regression test candidates
_Behaviors worth protecting with regression tests._
