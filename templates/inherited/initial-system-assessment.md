# Initial System Assessment

> Produced after first access to an inherited system to capture how it is built and run. Save the filled copy to `src/<engagement>/delivery/`.

## 1. System purpose
_What the system is for and who uses it._

## 2. Technology stack
_The languages, frameworks, and platforms in use._

## 3. Repository structure
_How the codebase is organized at the top level._

## 4. Main modules
_The principal modules or components and their roles._

## 5. Entry points
_How the application starts and where requests enter._

## 6. Build and run process
_How to build, configure, and run the system locally._

## 7. Database overview
_The databases used and their high-level structure._

## 8. External integrations
_Third-party services and systems the application depends on._

## 9. Test coverage overview
_What automated tests exist and how much they cover._

## 10. Deployment overview
_How the system is deployed and to which environments._

## 11. Documentation gaps
_Where existing documentation is missing or outdated._

## 12. Initial risks
_Early technical and delivery risks observed._

## 13. Recommended next assessment items
_What to investigate next to deepen understanding._
